# Scripts

Utility en setup scripts voor het AI RC Car project.

## Geplande scripts

- [ ] `setup_jetson.sh` - Basis Jetson Nano setup (dependencies, ROS2 installatie)
- [ ] `install_ros2.sh` - ROS2 Humble installatie op Ubuntu 20.04
- [ ] `install_realsense.sh` - Intel RealSense SDK installatie
- [ ] `test_sensors.py` - Alle sensoren testen en output weergeven
- [ ] `test_motors.py` - ESC en servo testen via PWM
- [ ] `calibrate_imu.py` - IMU kalibratie script
